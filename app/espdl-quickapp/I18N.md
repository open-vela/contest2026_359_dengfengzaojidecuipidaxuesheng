# 中文 / English

入口：设置 → 控制面板 → 个性化 → 界面语言。默认简体中文，支持 English。语言与全局字体独立，切换时保留字体选择。界面语言不改变离线语音模型或唤醒词。

系统界面使用 `glass_tr("应用自有的中文文案")`；英文词表在 `i18n/en.json`。未知条目保留原文。聊天正文、草稿、歌名、歌词、文件名和 Home Assistant 设备名直接显示原始数据，不在公共文本控件里自动翻译。协议标识、服务参数和用户指定的枚举值也保持原值。

QuickJS 提供 `system.language`（`zh-CN` 或 `en`）与 `system.translate(text)`。仅对应用拥有的界面文案显式调用翻译。相机、录音机、端侧识别和家居应用的源码与内置资源保持同步。HA 生成工具同时更新脚本授权哈希。

语言切换通过 LVGL 异步回调重建桌面及设置，避免删除正在分派事件的下拉控件。紧凑按钮和侧栏使用单行省略，长说明在独立文本区域换行；录音机标题、数量与提示分行排布。相机的透明点击层在按下和禁用时也保持透明。

选择在后台原子保存到 `/sdcard/veladesk-language.txt`，格式为 `VelaLanguage 1 en` 或 `VelaLanguage 1 zh-CN`。SD 不可用时本次切换仍生效，并提示未保存，不回退写 Flash。启动恢复不自动重写配置；无效版本、未知语言或损坏记录回退中文。用户主动选择优先于延迟的启动恢复。

## 验证

更新词表后运行：

```sh
python3 tools/generate_i18n.py
python3 tools/test_i18n.py --output /path/to/isolated/storage-test
```

真实 LVGL / QuickJS 界面检查：

```sh
python3 tools/render_all_ui.py \
  --apps /path/to/prepared/apps --cache /path/to/lvgl-host-cache \
  --output /path/to/isolated/ui-test \
  --harness-source app/espdl-quickapp/tests/render_i18n.c \
  --language-choice /path/to/isolated/language.txt
```

夹具覆盖两套主题、中英文设置、桌面及主要原生/QuickJS 页面、按钮文字边界、80 次切换、用户文字及字体保留。存储测试覆盖连续保存、跨进程恢复、损坏记录、用户选择优先与写入失败。前端回归另验证英文界面中的中文设备名及服务选项原值。渲染和目标对象编译不代表已经完整链接固件、烧录或通过实体屏幕验收。
