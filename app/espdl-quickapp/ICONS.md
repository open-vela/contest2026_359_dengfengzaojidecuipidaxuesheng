宿主结果不代表完整固件容量或实板验收，烧录仍须通过固件和数据分区边界检查。

## 交互状态

支持 Normal、PointerOver、Pressed、Selected、PointerOverSelected、PressedSelected。
米家家居点击或数值变化可触发 520ms 单次反馈，选中状态保留双色细节与浅填充。
页面首次绘制、刷新、悬停、焦点移动和取消按压不启动动画。
设置页亮度、音量、个性化和侧栏图标始终保持静止，页面重建不触发图标动画。
`glass_icon_set_active()` 只同步选择；按下、移入、焦点和取消由最近的控件拥有者传入。
普通文本与内联符号使用字体回退，单独图标使用分层 A8 遮罩。
六档实际尺寸为 14/16/20/24/32/64px；SVG 保留曲线与复合路径的孔洞。

## 开机与持续运行

`glass_icon_set_running(icon, true/false)` 独立控制真实工作状态。
QuickApp 可使用 `ui.setStyle(handle, {iconRunning: 1})`，关闭传 0。
这两个接口只更新视觉，不发送设备命令。

- 台灯：240ms 亮起暖色光束与地面光斑，运行时轻柔呼吸。
- 洗衣机：只旋转中间滚筒，机身和顶部按键保持静止。
- 风扇：叶片持续旋转；气流、收音、播放、信号与传输有对应局部反馈。
- 系统 118 个独立图标保留原始设计资料，当前原生运行时不编译其动画图层。
  18 个底色遮罩及度数符号作为配套资源保持静态，与主体对齐。
- `tools/material_icon_design.py` 是 SVG 与 LVGL 共用的逐项设计表，缺失定义会使生成失败。
  文件动正文/播放标志，声音动声波/拾音头，天气动雨雪/光芒，设备动工作部件。
  连成整体的外框保留原始路径，在框内添加局部反馈；机身、纸张、轨道不随之晃动。
- 离线画廊支持按类别运行、停止、搜索、六档尺寸和减少动态效果；导出 529 份 SVG。
  每个图标附中文动作说明，屏幕外的预览暂停。普通交互与显式运行状态相互独立，
  功能图标的持续动画只有调用方报告工作状态后才启动；确认、停止等操作仍默认单次反馈。
- 家居统一卡片和设备详情使用已观测状态；不使用待提交的开关意图启动动画。
  洗衣机只有 washing/rinsing/spinning/drying/running 才转动，单纯 on 不代表洗涤。
  未知、离线、编辑布局等情况停止；不猜测厂商数值状态的含义。

持续运行与 AnimatedIcon 的单次状态过渡分开。运行态语义对应持续播放器用途，
并非把所有选中图标永久循环。聊天历史结果卡仍是静态回执。

单次反馈最多 12 个并发，另有 128 个有界待播放项。运行态最多注册 64 个控件，
共用 40ms 定时器，每次最多更新 12 个可见图标，轮转服务。没有可见运行图标时
暂停定时器；重新显示时恢复。删除会清理注册与待执行回调。
“减少动态效果”保留已开启的光束/颜色等稳定状态，停止持续与单次运动。
运行控制不复制只读遮罩像素。颜色使用统一双色体系，台灯与灯泡运行时为暖光。

## 生成与检查

```sh
python -m pip install -r tools/material-icons-requirements.txt
python tools/generate_glass_icons.py
python tools/generate_icon_motion.py
python tools/export_material_icons.py --output <preview-directory>
python tools/test_material_icons.py --output <preview-directory>
python tools/generate_homeassistant_ui.py
node --test app/espdl-quickapp/tests/homeassistant_frontend.test.cjs
```

普通生成离线读取固定资源；`material_icon_shapes.py` 直接执行时才下载固定版本的原始资源。
`export_refined_icons.py` 保留为当前导出器的兼容入口。

`test_icon_motion.py` 使用真实 LVGL + ASan/UBSan，检查码位、像素变化与恢复、六种状态、
运行/关闭、洗衣机机身不动、隐藏恢复、减少动态效果与生命周期。
全量检查覆盖 59 × 6 = 354 组米家实际像素：单次反馈可见、持续动作可见、关闭恢复、
减少动态效果后保持静止；输出四页完整原生运行图谱。
`render_all_ui.py --harness-source .../render_settings_navigation.c` 检查实际页面。
SVG 画廊是设计预览；宿主截图、目标对象编译、完整固件链接和真实设备运行应分别记录。

实板 `desktop ui icon-status` 在桌面线程只读检查可见米家图标的字号、透明度、
运行/减少动态状态，以及每层遮罩的解码成功数和非透明像素覆盖。它不会控制家居。
