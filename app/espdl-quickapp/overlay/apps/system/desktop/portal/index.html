连接你的设备

输入设备屏幕上的 6 位令牌。
手机也可以扫描设备上的二维码，直接连接。

在设备上打开「扫码配置」，并让电脑、手机与设备连接同一 Wi-Fi。

Wi-Fi 配网

更换路由器，也能重新连接

先在设备的 Wi-Fi 页面开启配网热点，再让手机连接设备热点。手机提示「无互联网」时，请保留连接。填写路由器的网络名称和密码，试连成功后才保存；热点会保持开启，确认完成后请在设备上关闭。

密码为 8–63 个可打印 ASCII 字符，或 64 位十六进制密钥。密码只用于本次配网，不会回显。

Skills 与 MCP
