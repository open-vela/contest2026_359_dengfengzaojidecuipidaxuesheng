The links identify algorithm references, not immutable commit pins. Host fbank
comparison uses the installed kaldi-native-fbank 1.22.5 distribution and records
its wheel/library hash in the generated report. No upstream source files are
vendored by the independent fixed-profile C implementation.

The C graph/fbank runtime is experimental and not yet linked into board APP.
Model tensors remain external data assets. Original model/license provenance
is retained; implementing an operator does not relicense model weights.
