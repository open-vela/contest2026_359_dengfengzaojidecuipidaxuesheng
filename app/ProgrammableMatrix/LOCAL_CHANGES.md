# 大赛集成改动

`UPSTREAM.json` 记录首次原样导入的上游版本与文件摘要，不代表后续集成改动的摘要。

2026-11-05：在原有 GPIO10 入口之外增加 UART0（GPIO43/44、115200 8N1）的本地配网授权入口。发送下列命令并以 CR/LF 结束：

- `help`：显示命令。
- `jbox pair`：复用短按流程；未配置 Wi-Fi 时开启 180 秒 BLE 配网，已有配置时开启 120 秒 LAN 绑定。
- `jbox provision`：显式重新 BLE 配网。已有配置时通过一次软件重启进入窗口，进入窗口本身不擦除 NVS；普通重启、冷启动及崩溃不会自动进入。收到新配置后由官方配网流程保存，联网后开启 LAN 绑定窗口；保留已有控制密钥。

串口命令在原有按键任务中执行，只接受完整、有界的 ASCII 行；超长或二进制行整行丢弃，不回显输入。GPIO10 原短按、6 秒清 Wi-Fi、12 秒恢复出厂行为保留，串口不提供擦除命令。仅用于可信本地串口；Security1 无 PoP，LAN 领取绑定密钥仍要求可信局域网。

P4「设置 → JBOX 扩展板」负责从自身当前 STA 读取网络并加密发送，配网后鉴权并读取状态；密码不经过用户输入、JS 或 Agent。详情和实板验收范围见 `../../docs/JBOX_P4.md`。

宿主验证：`python tests/test_serial_pair.py`（GCC 在 PATH）。既有 `tests/run_native_tests.py`、客户端及脚本测试仍适用。构建仍采用本目录 ESP-IDF 工程和既有分区表；更新应用时保留 NVS。

Windows 构建注意：本机官方 GCC `esp-14.2.0_20251107` 在过长的工程路径宏映射下，于 SDK `esp_lcd_panel_rgb.c` 的 IRA 阶段稳定触发内部编译器崩溃；降低并发无效。同一源码、配置复制到短路径后全量构建通过。遇到此问题将本目录复制到短路径（例如 `D:/jbox`）重新构建，保留原配置和分区检查，不删除 SDK 模块或关闭编译检查。
