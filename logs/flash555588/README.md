使用归集工具输出真实会话，保留事件顺序和工具结果，不手工编造会话内容。

仓库根目录执行 `python3 tools/check_submission.py` 可检查清单和会话字段。
校验通过仍不能证明所有敏感信息已经人工审查完毕。不要为了补齐日期而导出其他项目的对话。
