# ESP32-P4 v1.0 最终固件测试报告

## 测试对象

- 开发板：ESP32-P4 Function-EV-Board
- 芯片：ESP32-P4 revision v1.0
- 固件：`nuttx.bin`
- 固件大小：2,968,512 bytes
- SHA-256：`46b825fb4410e15b13ea9030e054d9147d07480e2782e6b941b9abbda5e0db59`
- 烧录端口与偏移：COM7，`0x2000`

## 测试结果

本版本使用交叉工具链完成全量编译并生成 `nuttx.bin`。esptool 写入后镜像哈希校验通过，随后释放串口并执行真实断电冷启动。

冷启动日志确认 Flash 为 DIO 80 MHz、CPU 为 90 MHz，32 MiB PSRAM 初始化成功并进入 NuttShell。`desktop_main` 保持运行，QuickJS/OuO 自动启动；`ps` 可见桌面任务，NSH 可正常交互。

启动后的内存抽样结果为：内核堆总计 32,768 bytes、已用 4,608 bytes；用户堆总计 33,931,248 bytes、已用约 2,664,000 bytes、空闲约 31,267,248 bytes。持续观察 30 秒后已用内存未增长。

同一开发分支的前序实板回归还覆盖 1024×600 LVGL 全屏显示、GT911 点击/拖动坐标、连续复位、2048 与 OuO 交互。最终安全与并发修复版本已重新完成编译、烧录、哈希校验和冷启动；v3.2 芯片实板尚未回归。

## 结论

ESP32-P4 v1.0 最终固件满足本轮提交条件：构建成功、烧录校验通过、冷启动进入 NSH、PSRAM 与桌面/QuickJS 运行时正常，短时观察未发现堆增长。
