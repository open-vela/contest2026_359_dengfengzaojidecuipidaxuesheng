# Wi-Fi、BLE 与运行优化整理（2026-10-25）

本次整理包含 Wi-Fi／BLE 基础流程、内存与 CPU／声库回收、Grok 待机缓存、电脑 CLI 功能移除、唤醒运行和误唤醒修正，以及对应测试、历史说明和精简证据。浏览器目录与尚未选择的应用列表布局改动不在本次提交中。

Wi-Fi 页面自动扫描，连接后分别等待关联和本次 DHCP 租约，显示成功或明确的失败／超时反馈；旧 IP 不作为本次连接成功依据。网络后端仅操作无线接口。BLE 列表优先展示有名称、已配对、可连接的设备，折叠未命名广播并提示设备类型；命令仍经常驻蓝牙任务组的有界邮箱执行。命令线程空闲时阻塞等待，保留截止时间、连接代次与取消清理。

BLE 设备连接与鼠标仍使用已回退的角色互斥逻辑，未宣称同时连接、多设备共存或复用任意现有连接发送 HID。配对仍使用内部 Flash；未引入 SD 配对存储。此前独立 APP／连接复用候选发生卡死与蓝屏，已回退，不作为成功版本发布。

ESP-TTS 最后一次归还后保留 60 秒，再由桌面维护回收；正在借用的声库不释放。Grok 只在既有总预算内缓存指定待机帧，解压到原有缓冲，缺卡／预算不足时沿用原路径。移除电脑 CLI 页面、资源、桥接和对应测试；ESPClaw 原生工具不因此获得额外权限。

历史性能与唤醒结果分别见 [性能诊断](PERFORMANCE_2026-10-23.md)、[性能固件记录](PERFORMANCE_FLASH_2026-10-23.md)、[误唤醒排查](WAKE_FALSE_TRIGGER_2026-10-22.md)、[唤醒运行固件记录](WAKE_RUNTIME_FLASH_2026-10-23.md)。这些文档中的构建、烧录和未完成项均对应各自日期；不能推断本次整理已经重新烧录。
