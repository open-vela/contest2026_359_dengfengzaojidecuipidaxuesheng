## Source synchronization

This release uses the locally verified 04-v3-20260913/espdl-quickapp tree as the source baseline. It includes the current Home Assistant frontend, generated resource, authorization digest, BLE HID/touchpad implementation, C6 command entry, and frontend regression test. The old cloud v1 code is no longer the current feature baseline.

The file music_credentials.h was not uploaded because it contains a hard-coded API key. Firmware, ELF, MAP, model weights, and generated caches were also excluded from the source submission. Hardware state snapshots are stored under logs/2026-09-19/README.md.
