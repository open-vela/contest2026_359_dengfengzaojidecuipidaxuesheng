# 精简验证证据

本目录仅保存脱敏后的历史固件索引、可复现宿主检查结果与源码摘要；完整固件、ELF、Flash 备份、原始录音和本机构建缓存保留在本地。

`firmware-history.json` 逐项标明历史镜像摘要、PSRAM XIP 状态和当时验证边界。失败的连接复用镜像单独标明失败，不推荐部署。Wi-Fi 历史实测覆盖扫描、已保存网络重连、本次 DHCP 与成功反馈；未据此声称已经验证新 SSID／密码输入。蓝牙历史记录不构成并发、多设备或物理无闪屏验收。

本次上传前的检查记录保存于 `validation.json`；只汇总实际执行的结果。日志目录中的对话保留用户报告的卡死、蓝屏和回退过程，不能将失败实验改写成修复成功。
