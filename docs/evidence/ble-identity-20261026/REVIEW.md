# 新身份候选：第 2～4 项收尾

用户要求每轮鼠标候选更换实际 BLE 身份，已写入 AGENTS.md。本候选由标准 builder 每次生成新的合法静态随机地址及广播名后缀，记录 BLE-IDENTITY.json 和生成头哈希。身份固定编进镜像，运行重连和重启沿用；不改 C6 出厂 MAC/eFuse。同步阶段在主机事件任务中设置随机身份，核对读回及地址类型成功后才发布 HID ready；实际广播地址还需电脑扫描核对。

配对文件和 HID 用途文件按本候选完整身份地址命名，避免新地址重用旧地址的密钥；旧数据保留。首次配对、加密、订阅、重启持久化均须单独验证，不能把新身份成功说成旧身份配对兼容性通过。旧身份的上一候选与基线对照均发生连接异常，具体原因仍未确定；新 ID 用来隔离缓存影响，不预先宣称它修好了所有重连问题。

保留第 2～4 项的独立快照/逐连接计数、HID 访问所有者检查、SMP 保存后延后用途标记、保存失败回滚及 UI/CLI 明确反馈。固定 SDK 的 RAM 删除搬移按记录字节数修复，有实际 SDK 反例。应用角色互斥仍在，尚未开放普通蓝牙设备与鼠标并发。

主机身份设置与读回错误、每构建不同/镜像内稳定、名称/路径边界、独立文件命名、54 组文件失败、HID 邮箱及双主题 UI 已有回归。XIP、最终 ELF、连接池、烧录读回和本镜像实体显示验收仍需完成后单独登记。checkpatch 既有格式/CRLF 未全量通过，不取消编译/链接保护。
