# 多个普通 BLE 设备：NimBLE 多会话适配

后续候选 18 已保留本文件的多会话适配，并补齐同电脑 HID／业务 GATT 共连接。
最新部署及测试边界见 [共享 GATT 适配](BLE_SHARED_GATT_2026-10-27.md)；以下为候选 16 的历史记录。

本轮按用户“补全连接多个普通 BLE 设备”开发，继续自主自动验证。
沿用当前 SDK 的 NimBLE `ble_gap_connect`、`ble_gattc_*` 和 HCI 连接池，
不另写协议栈、不改 C6 固件。适配的是原先只保存一个普通设备的应用封装。
官方多连接也依赖应用连接管理及参数配置，不能将 SDK 的最大数字当成本工程实测容量。
参考：[乐鑫官方多连接指南](https://docs.espressif.com/projects/esp-idf/en/v6.1/esp32c6/api-guides/ble/ble-multiconnection-guide.html)。

## 容量与实现

按现有 C6 配套构建约束，将 P4 NimBLE 容量从 2 配置为 **3**：
**最多两个普通 BLE central 会话，并为鼠标 HID 保留一个名额**。
这是本轮配置／应用上限，不是 ESP32-C6 芯片能力的完整上限。

| 项目 | 本轮行为 |
|---|---|
| 普通设备连接 | 两个独立会话；建立连接过程一次发起一个，已建立连接可共存 |
| 准入 | 拒绝重复地址、超过容量及过时列表请求；connecting／closing 都占名额 |
| 会话身份 | 接纳连接时返回不复用的 generation；连接成功前即可准确取消该请求 |
| GATT | 每会话独立 API 锁、操作 token、结果和等待状态；不同设备可同时等待回包 |
| 通知 | 每会话独立 8 项队列、溢出计数和数据副本，单项最多 512 字节 |
| 配对／MTU | 只更新对应连接，不覆盖另一个设备 |
| 断开／超时 | 仅终止指定 generation，保留另一普通连接和 HID 名额 |
| 旧回调 | 检查 generation／handle／操作 token；旧连接成功回调不再盲目终止可能已复用的句柄 |
| 内存生命周期 | 断开／reset 唤醒原等待者；等待者退出前不复用其会话槽；大缓冲放初始化用户堆 |
| 扫描 | 与连接分开；重新扫描仍保留已连接设备行，避免设备停止广播后失去管理入口 |
| 页面 | 两个已连接设备均可选中管理；全局断开按钮只操作选中会话；状态栏按实际连接数计数 |
| QPK 应用 | status 返回 sessions；connect 返回 generation；多会话断开必须明确 generation |
| 应用所有权 | 应用只访问／清理自己接纳的连接及扫描；退出不再断开桌面当前选中的外部会话 |

普通会话的 `generation` 直接用于 GATT、通知和断开，不需要依赖“当前选中设备”。
旧标量快照保留为选中会话的兼容视图；`sessions` 是完整活动会话列表，
`connection_count` 是实际已连接普通设备数量，`session_count` 包含连接中／关闭中的会话。
预留数量不是连接数量。HCI／NPL 仍只由常驻 host 任务组执行。

CLI 示例：

```text
c6ble central devices
c6ble central connect <index> <scan-generation>
# 返回 BLE_SESSION generation=...
c6ble central sessions
c6ble central select <connection-generation>
c6ble central services <connection-generation>
c6ble central read <connection-generation> <value-handle>
c6ble central disconnect <connection-generation>
```

QPK `ble.status` 增加 `sessions`、`connectionCount`、`centralCapacity`。
`ble.connect` 的回执明确为 `accepted_not_connected`；成功建立以会话状态为准。
`ble.disconnect` 指定 `generation`；省略时只兼容恰好一个自有活动会话的场景。
GATT／通知需要该应用自有 generation；应用之间保留原有 BLE 所有权互斥策略，
本轮没有开放任意应用控制桌面或其他应用的连接。

## 验证边界

两个普通实体外设与 HID 三条真实连接同时传输、长时间性能及射频共存，
不由容量配置或宿主模拟结果证明。此前电脑的可连接 GATT 测试服务启动失败，
非连接广播只能验证扫描，不能当成普通连接。不会连接身份不明的周边设备来凑数量。
同一电脑的业务 GATT 与 HID 共用连接的应用协议仍未实现；本轮是多个外部 BLE 设备。
冷断电启动及实体显示验收单独保留状态，不继承旧候选结果。
稳定下载 5 Mbps 仍是 Wi-Fi 设计目标，吞吐验收维持 `skipped_by_user`，本轮未安排。
