## 本轮补全

| 能力／问题 | 本轮实现 | 边界 |
|---|---|---|
| 已连接普通 BLE 外设时再次搜索 | 独立扫描锁、扫描 callback/token，保留连接 callback/token | 仍只管理一个普通 central 会话 |
| 停止搜索 | `scan_stop(scan_generation)` 只取消指定代次扫描 | 不再借用会取消正在进行的 GATT 的通用取消路径 |
| 搜索中读 GATT | 扫描不占 GATT API 锁，连接代次、对端、MTU／通知路径独立保留 | 宿主替身验证不等于真实双连接空口验证 |
| GATT 等待超时 | 使用单调时钟 15 秒期限 | 邮箱唤醒不再扣减 GATT 等待次数；不代表重做整个邮箱协议 |
| 受控测试设备发现 | 可按完整 128 位服务 UUID 筛选 | 广播是发现线索，不构成认证；过滤值由服务持有副本 |
| 过时诊断请求 | 停止扫描和断开连接要求代次；校验数值范围、下标和属性句柄 | 保留旧 API 的兼容包装，不宣称覆盖所有旧回调／句柄复用竞态 |
| 自主 GATT 诊断 | 扫描、列表、连接／断开、服务／特征发现、读、MTU、配对、通知出队 | 数据只输出长度／FNV 校验值；未增加任意写入 CLI |
| 页面 | 加密连接后可搜索；搜索按钮切换为停止搜索；取消已接纳搜索只停对应扫描 | 配对、断开、鼠标入口继续各自使用原生命周期 |

命令入口为 `c6ble central`。服务 UUID 输入使用标准 36 字符格式，内部转为蓝牙广播的低字节在前顺序。
连接命令引用扫描列表下标及扫描代次；GATT／断开命令引用连接代次。
所有实际 GAP／GATT 命令仍由常驻 host 任务组处理，NSH／UI 不直接使用 HCI／NPL 描述符。
